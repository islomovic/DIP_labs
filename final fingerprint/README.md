# Final Fingerprint Project

Files included:

- `final_fingerprint_colab.ipynb` — main Google Colab notebook
- `fingerprint_pipeline.py` — Python script version
- `requirements.txt`
- `pic/` — put your fingerprint photos here
- `output/` — generated results are saved here

## Recommended use
Open `final_fingerprint_colab.ipynb` in Google Colab and run cells from top to bottom.
Upload your images into the `pic/` folder or use the upload cell in Colab.
